
# こむぎ野区ベーカリー情報検索 MCPサーバー

## 1. 概要

本サーバーは、卒業論文におけるAIレコメンド実験のために作成したMCP（Model Context Protocol）サーバーです。

架空の地域「こむぎ県こむぎ野区」に所在する30店舗のベーカリーについて、CSVファイルに登録された情報をAIに提供します。

登録されている店舗名、住所、開業日、商品、サービス等はすべて実験用の架空情報です。

## 2. 研究目的

本実験では、AIに提供する店舗情報の充実度が、生成AIによる店舗推薦にどのような影響を与えるかを検証します。

MCP-AとMCP-Bでは、サーバーのプログラム、検索機能、CSVの列構成、店舗数、店舗属性の該当・非該当を統一します。

両条件で変更するのは、bakery.csvに記載された属性の説明文のみです。

## 3. 登録店舗

登録店舗数：30店舗

対象地域：こむぎ県こむぎ野区（架空）

店舗名：ベーカリー1～ベーカリー30

すべて実験用に設定した架空店舗です。

## 4. CSVの項目

各店舗について以下の14項目を管理します。

1. 店舗名
2. 開業日
3. 住所
4. ドイツパン販売
5. 天然酵母使用
6. 国産小麦使用
7. 健康志向
8. PayPay対応
9. 独立経営
10. 手土産対応
11. 子連れ対応
12. 職人のこだわり
13. デリバリー対応
14. 予約・取り置き対応

## 5. 情報の取り扱い

店舗情報のデータソースはbakery.csvです。

CSVに記載された説明文を変更・要約・補完せずに提供します。

「－」は、その属性について説明文が登録されていないことを意味します。

「－」は、その商品やサービスに対応していないことを意味するものではありません。

未記載の属性は、登録されている属性と区別して返します。

店舗の推薦順位や評価点はサーバー側では計算しません。

本サーバーは読み取り専用です。

## 6. MCPツール

### list_bakeries

登録されている全店舗の基本情報を取得します。

返却項目：
- 店舗名
- 開業日
- 住所

### get_bakery

指定した店舗名に完全一致する店舗の詳細情報を取得します。

引数：
- name：店舗名

### search_bakeries

指定したキーワードを含む店舗を検索します。

検索対象：
- 店舗名
- 住所
- 登録されている属性の説明文

検索方法は部分文字列一致です。

説明文が未記載の属性は検索対象に含めません。

引数：
- keyword：検索キーワード

### get_all_bakeries

全30店舗について、登録されている属性情報と未記載の属性を取得します。

以下を実行します。

通信方式はstdioです。

MCPに対応するクライアントから接続して使用します。

## 11. MCP-AとMCP-Bの共通条件

以下の条件を統一します。

- server.py
- requirements.txt
- README.md
- MCPツールの種類
- MCPツールの引数
- CSVの列構成
- 店舗数
- 店舗名
- 開業日
- 住所
- 11属性の該当・非該当

変更するのはbakery.csvに記載された説明文のみです。

## 12. 実験上の注意

本サーバーが提供する情報は、すべて実験用の架空店舗データです。

登録されていない属性は、対応していないことを意味しません。

キーワード検索は文字列一致に基づくため、意味が近い表現でも文字列が一致しない場合は検索結果に含まれないことがあります。

AIによる店舗推薦結果は、使用モデル、質問文、ツールの呼び出し方などによって変化する可能性があります。

本サーバーは、実在する店舗の検索や実際の店舗情報の提供を目的としていません。
