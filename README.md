
# 架空ベーカリー情報検索 MCPサーバー

## 概要

本サーバーは、卒業論文におけるAIレコメンド実験のために作成したMCP（Model Context Protocol）サーバーです。

架空の地域「こむぎ県こむぎ野区」に所在する30店舗のベーカリーについて、CSVファイルに登録された情報をAIに提供します。

本サーバーに登録されている店舗・住所・開業日・商品・サービス等はすべて実験用の架空情報です。

## 研究目的

本実験では、AIに提供する店舗情報の充実度が、ベーカリーの推薦結果にどのような影響を与えるかを検証します。

MCP-AとMCP-Bでは、サーバーの構造、検索機能、処理方法を同一とし、`bakery.csv` に登録する説明文のみを変更します。

## 登録情報

各店舗について、以下の14項目を管理します。

1. 店舗名
2. 開業日
3. 住所
4. ドイツパン販売
5. 天然酵母使用
6. 国産小麦使用
7. 健康志向
8. PayPay対応
9. 独立経営
10. 手土産対応
11. 子連れ対応
12. 職人のこだわり
13. デリバリー対応
14. 予約・取り置き対応

登録店舗数は30店舗です。

## 情報の取り扱い

- `bakery.csv` を店舗情報のデータソースとします。
- CSVに記載された情報を変更・補完せずに提供します。
- 「－」は、その属性に関する説明文が登録されていないことを意味します。
- 「－」は、その属性に対応していないことを意味するものではありません。
- 登録されていない店舗情報は、登録されていないものとして扱います。
- 店舗情報の検索時には、登録されている説明文を参照します。
- 店舗の推薦順位や評価点はサーバー側では計算しません。
- 本サーバーは読み取り専用であり、店舗データの変更機能は提供しません。

## 提供するMCPツール

### list_bakeries

登録されている全30店舗の基本情報を取得します。

### get_bakery

指定した店舗名に一致する店舗の登録情報を取得します。

### search_bakeries

指定したキーワードに関連する店舗情報を検索します。

検索はCSVに登録された店舗名・住所・説明文を対象とし、文字列の一致によって行います。

### get_all_bakeries

全30店舗について、登録されているすべての情報を取得します。

## ファイル構成

- `README.md`：サーバーの説明
- `requirements.txt`：必要なPythonライブラリ
- `server.py`：MCPサーバー本体
- `bakery.csv`：30店舗の情報

## 実行方法

Python 3.10以上を使用します。

必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

MCPサーバーを起動します。

```bash
python server.py
```

本サーバーは標準入出力（stdio）によるMCP通信を使用します。

## 実験条件

MCP-AとMCP-Bでは以下の条件を共通とします。

- Pythonプログラム
- MCPツール名と引数
- CSVの列構成
- 登録店舗数
- 店舗名
- 開業日
- 住所
- 11属性の該当・非該当の組み合わせ
- 検索・取得処理
- サーバー起動方式

両条件で変更するのは、`bakery.csv` に登録する属性の説明文のみです。

## 注意事項

本サーバーは架空店舗を用いた研究実験専用です。実在する店舗の検索や実際の店舗情報の提供を目的としたものではありません。
